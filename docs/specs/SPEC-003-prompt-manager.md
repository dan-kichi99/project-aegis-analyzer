# SPEC-003: Prompt Manager 実装

## 目的
AIへ送信するプロンプトを一元管理し、呼び出し側（Controller等）からプロンプト構築処理を分離する。

## 責務
ユーザーからの入力（質問）を受け取り、AI送信用にフォーマットしたプロンプト文字列を生成して返却する。

## 入力
- `question` (str): ユーザーから入力された質問テキスト

## 出力
- `prompt` (str): AIモデルへ送信するためのプロンプト文字列

## 今回実装しないもの（YAGNI）
- ジャンル判定（Web / Crypto / Rev 等のカテゴリ切り替え）
- OpenAI API との通信処理
- 会話履歴（コンテキスト）の保持および管理
- 設定ファイル（.env や yaml 等）からのテンプレート読み込み
- ログ出力機能
- GUI
