# Demo Scenario

Project Aegis AnalyzerのGUIを30〜60秒で紹介するための操作手順です。動画編集や自動撮影の仕組みは提供していません。この手順に沿って画面収録してください。

## 準備

- 第三者のCTF問題・著作物は使用しません。
- 自作のSample Fileのみを使用してください（例：`FLAG{sample_demo_only}` のような自作Flag文字列を含む、自分で作成した`.txt`または`.zip`）。
- Sample Fileは新しい解析機能を追加するためのものではなく、既存機能（Strings抽出・Flag候補検出）を示すためだけに使用してください。

## 手順（目安：合計30〜60秒）

1. **GUI起動**（約5秒）
   `.\.venv\Scripts\python.exe -m app.gui_main` を実行し、初期画面を表示する。
2. **問題文入力**（約5秒）
   「問題文」欄に短いSample問題文を入力する（例：「添付ファイルからFlagを探してください」）。
3. **自作Sampleファイル追加**（約5秒）
   「ファイル追加」ボタンから、自作Flag文字列を含むSample Fileを1件選択する。
4. **解析開始**（約5秒）
   「解析準備」ボタンをクリックし、Progress欄で解析が進行する様子を見せる。
5. **Flag候補表示**（約10秒）
   解析完了後、「Flag候補」欄に検出結果が表示されることを見せる。あわせて「回答」「理由」欄も画面に収める。
6. **Copy**（約5秒）
   「Flag候補」ラベルをDouble-Click、または「コピー」ボタンをクリックし、コピー完了Messageが表示されることを見せる。
7. **結果 / 理由確認**（約10秒）
   「カテゴリ」「信頼度」「次のAction」欄も含め、結果全体を俯瞰して締める。

## 収録時の注意

- APIキーや個人Pathが画面・Terminalに映り込まないようにする。
- Sample File名・問題文に個人情報を含めない。
- 実際のOpenAI通信を含める場合は、通信内容にSecretが映らないことを確認する（AIキー未設定でもFast-Path解析のみでDemo可能）。
