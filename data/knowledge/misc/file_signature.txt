File Signatures and Magic Bytes Verification

File signatures (magic bytes) are fixed hex byte sequences at the beginning of files that identify their true file format regardless of extension.
Examples of common magic bytes:
- PNG: 89 50 4E 47 0D 0A 1A 0A (.PNG....)
- JPEG: FF D8 FF E0 or FF D8 FF E1
- GIF: 47 49 46 38 (GIF87a / GIF89a)
- ZIP: 50 4B 03 04 (PK..)
- ELF binary: 7F 45 4C 46 (.ELF)
- PDF: 25 50 44 46 (%PDF)
In CTF challenges, extensions are often changed or header magic bytes corrupted.
Fix headers using hex editors (xxd, GHex) or analyze true format using file command: 'file filename'.
